# vehicle_sales_analysis

Web development project featuring vehicle sales data analysis.

This web development project was created to display and interact with data analysis based on a vehicle sales dataset.

The application features a checkbox and a button: the checkbox allows the user to generate a histogram to visualize the distribution of odometer readings.

The button allows the user to create a scatter plot to visualize the relationship between odometer readings and price.

This web application can be accessed at:
https://vehicle-sales-analysis-05to.onrender.com/
